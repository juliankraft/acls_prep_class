# Let's get your computer ready for the ACLS master program

## Day 1 - Setting up your development environment

### objectives

- install WSL (Windows Subsystem for Linux)
- install a package manager, Homebrew (macOS)
- install Mamba - a Python environment manager
- install R and RStudio
- create a GitHub account and link it to your student account
- set up an SSH key and link it to your GitHub account
- decide on your IDE (Visual Studio Code or PyCharm)

## Day 2 - Getting started with Python

### objectives
- have your IDE of choice up and running
- have a Python environment ready for your classes
- clone and create a GitHub repository
- run Python code and create some yourself
- run Jupyter Notebooks and create one yourself
